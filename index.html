HERMES · void, plasma, signal

Dark surface (#06000F void), plum field, with cyan / pink / coral / plum / acid-green accents. Glassmorphism on surface-4 (translucent purple), Outfit display + JetBrains Mono. Used by HERMES Workshop modules and the HERMES splash custom widget.

Where it lives

Single source of truth and where consumers pick it up.

  • tokens/themes/hermes.json — token source. Edit here, regenerate.
  • scripts/build-tokens.ts — generator. Reads every tokens/themes/*.json, writes dist/<name>.css.
  • dist/hermes.css — generated CSS. This page consumes it.
  • deliverables/kit-react/src/tokens/hermes.css — vendor copy for React consumers.
  • ~/projects/odt/architecture/cda/apps/shared/hermes-theme.css — original donor (kept for cross-app reference).
