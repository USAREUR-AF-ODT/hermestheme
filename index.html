Variants

HERMES ships in four tokens files. Same component CSS, only values change.

hermes · canon
Void / cyan / pink / coral / plum / green
data-theme="hermes"
hermes-light
Lavender field, deep purple ink
data-theme="hermes-light"
hermes-mono
Pure grayscale, identical ramps
data-theme="hermes-mono"
hermes-toxic
Acid green field, signal-yellow accent
data-theme="hermes-toxic"

Where it lives

Single source of truth and where consumers pick it up.

  • tokens/themes/hermes.json — token source. Edit here, regenerate.
  • scripts/build-tokens.ts — generator. Reads every tokens/themes/*.json, writes dist/<name>.css.
  • dist/hermes.css — generated CSS. This page consumes it.
  • deliverables/kit-react/src/tokens/hermes.css — vendor copy for React consumers.
  • deliverables/kit-react/src/components/*.tsx — 85 component .tsx files, 160 exports.
  • deliverables/kit-react/src/charts/*.tsx — 4 chart primitives (BrandedBarChart, BrandedDonut, BrandedLineChart, BrandedPlot).
